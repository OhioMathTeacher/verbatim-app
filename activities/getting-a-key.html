🔑 Getting an AI key

The activities don't come with an AI attached. You point one at an AI service of your choosing, using a key — a long string of letters and numbers that tells the service the requests are yours. Getting one takes about three minutes and doesn't require knowing anything about programming.

Why a key, rather than just a login

The chat website you may already use (chat.deepseek.com, ChatGPT and so on) is a finished product. The activities here are a different page talking to the same underlying model directly, and a key is how that page identifies itself. It is the ordinary way this is done; it is not a developer-only thing.

Practically, it also means the conversation is yours. It isn't routed through anyone else's server, and no account of ours is involved.

DeepSeek, step by step

  1. Go to platform.deepseek.com and sign up. This is the developer platform, which is a different place from the chat website — the same account works for both.
  2. Find API keys in the left-hand menu.
  3. Press Create API Key. Give it a name you'll recognise later, such as verbatim, and an expiry date if you'd like one.
  4. Press Submit. The key appears once and only once — copy it now. If you lose it, no harm done: delete it and make another.
  5. Open any activity, press AI Setup, choose DeepSeek, and paste the key in. It turns into dots once saved.

Your key stays in your browser. It is not written into the activity page, not sent to us, and not stored anywhere but on your own device. If you clear your browser data it will be gone and you'll simply paste it again.

What it costs

Very little. DeepSeek has no permanent free API tier, but new developer accounts have generally started with a grant of a few million tokens — enough to run these activities many times over. It isn't guaranteed, so check the billing page when you sign up.

Beyond any grant, the rates are low enough that the arithmetic is almost comic. A twenty-minute conversation of this kind runs to a few thousand tokens, which is a fraction of a cent. A whole class of thirty would cost well under a dollar.

If DeepSeek is awkward

Seven other services are in the picker — OpenAI, Gemini, Qwen, Zhipu, Moonshot, Groq and OpenRouter — and every one works the same way: sign up, make a key, paste it in. The activity itself doesn't care which you choose, though for a class it's simpler if everyone uses the same one.
